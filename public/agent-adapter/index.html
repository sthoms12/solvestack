BRING YOUR OWN AGENT

SolveStack is the evidence plane. Your approved tool is the reviewer.

SolveStack does not include an AI service. From any session, export an Agent pack — a ZIP with redacted Markdown and JSON — then open it in an organization-approved assistant.

See the pack layout Open the workspace

01 / PACK CONTENTS

What the agent pack includes

  • AGENT.md — instructions that forbid inventing missing facts
  • knowledge.md — redacted human-readable investigation summary
  • session.redacted.json — structured session without attachment binaries
  • evidence-manifest.json — filenames and MIME types only

Credential-like strings, bearer tokens, emails, and raw IPv4 addresses are replaced with [REDACTED] before export. Review the pack yourself before sharing it with any external tool.

02 / LOCAL PROTOCOL

Adapter rules

  1. Keep the investigation in SolveStack (or an encrypted vault) on devices you control.
  2. Export the agent pack only after you are ready to share a redacted record.
  3. Point an approved tool at AGENT.md + session.redacted.json.
  4. Treat suggestions as provisional until a human validates them against evidence.

Optional local helper: bun scripts/agent-pack-inspect.mjs path/to/pack.zip lists pack files and checks that AGENT.md is present.

BOUNDARIES

Still local-first

No SolveStack account. No cloud database. No hosted model. Encrypted vaults and agent packs are files you move deliberately.
