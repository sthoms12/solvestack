HOW DATA IS HANDLED

What stays local and what touches the network.

01

Browser-local storage (IndexedDB & OPFS)

Core troubleshooting sessions, timeline entries, hypotheses, tasks, preferences, and attachments are stored locally in IndexedDB inside your current browser profile. Larger evidence files prefer the Origin Private File System (OPFS) when available. Browser storage is tied to the exact origin and browser profile and does not automatically sync across browsers, devices, or private-browsing windows.

STAYS ON YOUR DEVICE
02

Encrypted vaults & local sync folders

You can optionally export an AES-GCM encrypted vault file protected by a user-held passphrase, or connect a local sync folder in browsers that support the File System Access API (such as Chrome and Edge on desktop). Encryption and decryption happen entirely inside your browser. SolveStack never receives your passphrase, vault files, or folder contents.

USER-HELD ENCRYPTION
03

No accounts, cookies, or server database

SolveStack does not require an account, does not set cookies, does not run ads or third-party trackers, and does not maintain a server database of user investigations. Your troubleshooting notes, evidence files, attachments, and vault data are never uploaded to a SolveStack server.

ZERO ACCOUNT OVERHEAD
04

Cookieless analytics (Dataflare)

This site uses Dataflare, an analytics tool we self-host in our own Cloudflare account. It is cookieless — it sets no cookies and stores nothing on your device. It records pageviews, the referring site, basic device and browser information, and anonymous interaction events (such as case_resolved — never your troubleshooting notes, evidence, attachments, or vault data) so we can understand which content and workflows are useful. Analytics data is kept for 90 days and is never sold or shared.

COOKIELESS · 90-DAY RETENTION
05

Hosting & infrastructure logs

The static site files are delivered through Cloudflare infrastructure, which processes ordinary web request metadata — such as IP address, browser user agent, and requested URL — to serve pages reliably and protect the site from abuse.

STANDARD WEB DELIVERY
06

Exports, agent packs & external services

When you choose to export Markdown, standalone HTML, JSON, ZIP archives, or a redacted agent pack and move or upload that file to an external file share, wiki, or third-party AI tool, that external service's privacy, security, and retention policies apply. Always review exported files and redact credentials, tokens, personal data, and confidential evidence before sharing. Links to external sites are governed by those sites' own policies.

USER-INITIATED MOVEMENT
07

Deleting local data & security boundaries

Export a JSON backup or encrypted vault first if you want to preserve your records. You can delete local workspace data at any time through your browser's site-storage controls; clearing site data removes the local browser copy. Local storage reduces server-side exposure, but it does not protect against unlocked devices, compromised browser profiles, malicious browser extensions, or unsafe handling of exported files.

YOUR DEVICE BOUNDARY
