QUESTIONS

Using the template library.

Are all SolveStack templates free to copy?

Yes. Every template includes a plain-text copy-paste version you can use in any ticket, wiki, or editor, or you can run the investigation locally in SolveStack with no account.

Which template should I pick during a live IT outage?

Start with the incident-specific checklist (VPN, DNS, network, sign-in, expired certificate, disk full, email delivery, or backup restore) to isolate the fault quickly, then move to the RCA or blameless postmortem template after service is restored.
